# 蓝图：网页分类、标签管理

状态：已实现（2026-11-17）。roadmap v2「分类、账户、标签的网页管理」中的分类和标签（账户已做）。

## 动机

分类要整体重新整理（改名、换 emoji、调顺序、挪到别的一级下面），现在只能 ssh 上去用命令行。改成在网页里直接改，以后日常调整也在手机上完成。

## 原则

- emoji 是名字的一部分（`🍜 餐饮`），不加字段；网页仍取名字开头的 emoji 当图标。
- 一律原地修改：账目按 id 引用分类，改名、换 emoji、调顺序、换一级，历史账目都跟着走，不做旧 → 新的映射。
- 有账目在用的分类不能删（409）。需要拆分或合并时，先在账目列表里把账一笔笔改到别的分类，改空了再删。批量改账以后再说。
- 规则和命令行共用 `catalog.rs` 里的同一套代码，命令行行为不变。

## 接口（网页会话鉴权）

`GET /api/catalog` 不变，分类本来就带 `id、kind、parent_id、name、key`，按 `position` 排。写操作都在一个事务里完成，成功后返回全部分类的新列表 `{ "categories": [...] }`（形状同 catalog），网页直接替换。

| 接口 | 请求 | 成功 | 失败 |
|---|---|---|---|
| `POST /api/categories` | `{ "kind", "parent_id", "name", "key" }` | 201 | 400 名称或 key 不合规；409 同级重名、key 已被占用；409 上级不是同类型的一级 |
| `PUT /api/categories/:id` | `{ "parent_id", "name", "key" }`，整体替换 | 200 | 404；409 同上；409 有二级的一级不能挪到别的一级下面；409 兜底分类必须保持一级、key 不能改 |
| `DELETE /api/categories/:id` | — | 204 | 404；409「还有 N 笔账目在用，不能删除」；409「下面还有 N 个二级，先删它们」；409「兜底分类不能删」 |
| `POST /api/categories/:id/move` | `{ "to": 0 }`，同级内从 0 开始，超出范围就夹到两端 | 200 | 404 |

- `kind` 只在新建时给，以后不能改（改了会和已有账目的类型对不上）。
- 改 `parent_id` 就是把它挪到另一个一级下面（或改成一级），排在新同级的最后。挪的时候它自己不能带着二级。
- 名称规则和命令行一样：去掉首尾空白，不能为空，不能含 `/` 或换行。同一个上级下不能重名（表里本来就有唯一索引）。
- `key` 是给模型看的标识：小写英文、数字或下划线，全局唯一。模型看到的是 `key: 一级/二级`，具体含义靠名字来表达。
  - 可以为空或省略：新建时由服务器生成 `c<id>`；PUT 时为空表示保持原值。
  - 随时可以改：账目、草稿、识别留存都只认 id，key 只在识别时拼进提示词、当场换成 id，改了下次识别就生效，不影响历史数据。
  - 兜底分类（`other` / `other_in`）的 key 不能改，代码靠它们认出「其他」。

## 标签

| 接口 | 请求 | 成功 | 失败 |
|---|---|---|---|
| `POST /api/tags` | `{ "name" }` | 201，`{ "tags": [...] }` | 400 名称不合规；409 重名 |
| `PUT /api/tags/:id` | `{ "name" }` | 200，`{ "tags": [...] }` | 404；409 重名 |
| `DELETE /api/tags/:id` | — | 204 | 404；409「还有 N 笔账目在用，不能删除」 |

- 名称规则和分类相同；按 id 排序，不做调整顺序。
- 网页：设置页「记账」那组再加一行「标签」，列表加编辑面板（名称、删除），底部「添加标签」。

## 对快捷指令和识别的影响

- 快捷指令不用改。菜单每次请求都现读目录，改完立即生效。
- 草稿只存 id。快捷指令还没走完时分类被删了，`/step` 会返回 400，重新截图即可（和现在一样）。
- 识别详情里，已删分类显示为「当时的分类已不在」（v7 已经是这样）。

## 网页

- 设置页「记账」那组加一行「分类」，进去后分「支出 / 收入」两个标签页。一级列表点进去看它的二级，按住拖动排序，交互和财富页的账户排序一样。
- 每一行点开是编辑面板：名称（emoji 直接打在名字里）、key、上级（可以选「无，作为一级」）、删除。删不掉时把服务器的原因弹出来。
- 底部「添加分类」。

## 不做

- 删除时把账目合并或映射到别的分类。
- 批量改账目的分类。
- emoji 选择器（直接用系统键盘输入 emoji）。
- 改分类的类型（支出 ↔ 收入）。
