# 头脑风暴：怎么用账目的位置

数据来源见 [位置蓝图](../blueprints/location.md)：截图记账**入账后**补采的手机位置（WGS-84），存在 `recognitions` 上，网页手填的账没有位置。因为是入账后才采的，它影响不了当次的识别和菜单，只能拿来事后看、事后归类。

## 已定

- **账目详情跳 Apple 地图**：链接用 `https://maps.apple.com/?ll=纬度,经度&q=商家`，iPhone 上会直接打开地图 App。不做逆地理编码，不加依赖。国内直接传 WGS-84 实测往西北偏几百米，链接里改传 GCJ-02（已实现，2026-11-24）。
- **用历史位置给新账做参考**：以后再说。

## 方向：像「照片」那样按地点和时间看账

参照 iPhone「照片」：按地点分组、按时间翻，**先不画地图**。分组的是「地方」（城市、旅行），不是坐标点。

- 地名：快捷指令采位置时顺手带上城市（系统在手机上解析），已实现（v11，2026-11-24）。
- 旅行：离常驻地远、连续几天的账目归成一次旅行，「🚄 火车飞机」「🏨 酒店住宿」用来补齐出发前买票、订房这几笔。旅行由位置、时间、分类推导，不另存。规则细节等有了真实数据再定。
